Monospace pill for short labels, tags, status markers, and inline data tokens.

```jsx
<Chip>● HAPPENS HERE</Chip>
<Chip variant="neutral">reads all</Chip>
<Chip variant="ghost">Q1</Chip>
<Chip variant="outline">200 tok</Chip>
```

- `solid` (default) is the coral spotlight pill; `neutral` is an ink token on light; `ghost` is for dark surfaces; `outline` is a quiet light-surface tag.
- Glyphs like `●`, `→`, `✓` read well inside it — never emoji.
