The invoice task21 / 30

Make the acceptance contract explicit

GOAL: export invoice net, VAT and gross values to CSV.SCOPE: invoice export code; preserve existing tests.VERIFY: pytest tests/test_export.py -qCASES: 21% VAT, zero VAT, rounding, quoted CSV fields.LIMIT: three repair attempts; then stop and report.EVIDENCE: diff, command, exit status, failures and gaps.
Pair this request with an enforced runtime budget and a review of the resulting artifact.

4 · Numbers

Agent · the loop09 / 30

An agent is a loop

  1. 01Propose: the model chooses the next action.
  2. 02Run: the harness executes it under the configured permissions.
  3. 03Observe: the result returns as context for the next step.
  4. 04Check: stop when the task is verified, or ask when blocked.
In a live run or a finished transcript, point to one tool call and its result. That is one lap of the loop.

6 · Before / after

Model choice15 / 30

Escalate when the evidence points to a need

01Start:

use a configuration that has met the acceptance bar on similar work.

02Diagnose:

missing facts, a broken tool and hard reasoning call for different fixes.

03Compare:

try supported effort or model changes against the same checks and budget.

There is no universal “effort first” ladder. Re-evaluate defaults when the task or model changes.
