The invoice task

Make the acceptance
contract explicit

1GOAL: export invoice net, VAT and gross values to CSV.
2SCOPE: invoice export code; preserve existing tests.
3VERIFY: pytest tests/test_export.py -q
4CASES: 21% VAT, zero VAT, rounding, quoted CSV fields.
5LIMIT: three repair attempts; then stop and report.
6EVIDENCE: diff, command, exit status, failures and gaps.

Pair this request with an enforced runtime budget and a review of the resulting artifact.

Agent · the loop

An agent is a loop

  1. 1

    Propose: the model chooses the next action.

  2. 2

    Run: the harness executes it under the configured permissions.

  3. 3

    Observe: the result returns as context for the next step.

  4. 4

    Check: stop when the task is verified, or ask when blocked.

In a live run or a finished transcript, point to one tool call and its result. That is one lap of the loop.
