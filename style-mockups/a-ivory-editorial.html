1 · Title

In practice

Start with three changes

Instructions

Remove conflicting or obsolete rules; preserve real constraints.

Verification

Make done depend on evidence tied to the task.

Measurement

Compare configurations by outcomes, cost and review effort.

Skills, caching and delegation support these three habits.2

4 · Numbers

Agent · the loop

An agent
is a loop

  1. 1Propose: the model chooses the next action.
  2. 2Run: the harness executes it under the configured permissions.
  3. 3Observe: the result returns as context for the next step.
  4. 4Check: stop when the task is verified, or ask when blocked.
In a live run or a finished transcript, point to one tool call and its result. That is one lap of the loop.9
