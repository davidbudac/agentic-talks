1 · Title

In practice2

Start with three changes

Instructions

Remove conflicting or obsolete rules; preserve real constraints.

Verification

Make done depend on evidence tied to the task.

Measurement

Compare configurations by outcomes, cost and review effort.

Skills, caching and delegation support these three habits.

The invoice task21

Make the acceptance contract explicit

request to Claude6 lines
GOAL: export invoice net, VAT and gross values to CSV.SCOPE: invoice export code; preserve existing tests.VERIFY: pytest tests/test_export.py -qCASES: 21% VAT, zero VAT, rounding, quoted CSV fields.LIMIT: three repair attempts; then stop and report.EVIDENCE: diff, command, exit status, failures and gaps.

Pair this request with an enforced runtime budget and a review of the resulting artifact.

4 · Numbers

Agent · the loop9

An agent is a loop

  • Propose: the model chooses the next action.
  • Run: the harness executes it under the configured permissions.
  • Observe: the result returns as context for the next step.
  • Check: stop when the task is verified, or ask when blocked.

In a live run or a finished transcript, point to one tool call and its result. That is one lap of the loop.
