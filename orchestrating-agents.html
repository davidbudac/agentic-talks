Failure mode01

Runaway loops

An agent retries a failing approach and never asks for help.

Fix: a hard cap on turns or tokens per task, enforced by the orchestrator.

Failure mode 2 of 3
Failure mode02

Merge conflicts between agents

Parallel agents edit the same files. Nobody sees it until merge time.

Fix: worktrees keep agents apart while they work. When tasks overlap, a human sets the order.

Review bottlenecks

Orchestration multiplies pull requests. It doesn't multiply reviewers.

Fix: grow review capacity with agent throughput, or throttle the agents.

MCP's strengths

Where MCP earns its place

Typed schemas

The agent reads the arguments instead of guessing them.

Auth in the protocol

Remote servers use OAuth 2.1, with no token pasted into a shell.

No shell needed

Works in the Claude desktop app and claude.ai connectors.

27
  1. Tools
  2. Skills
  3. MCP vs CLI
CLI's strengths

Where a plain CLI wins

Composable

Pipes, grep and jq: idioms the model has seen endlessly.

Nothing to maintain

No schema to write or keep in sync with the tool.

Lean by default

A one-line mention; the agent reads --help only when needed.
