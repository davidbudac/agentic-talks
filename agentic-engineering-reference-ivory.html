Worked arithmetic · Optional reference · Back to the talk

Growing history can produce quadratic input volume

Assume n calls; initial input B; each call adds d tokens. No pruning, compaction or window cap in this toy model. Input at call k = B + (k − 1)d Total input = nB + d × n(n − 1) / 2 B = 5,000; d = 2,000; n = 10 Last call = 23,000; total input = 140,000 tokens.

This is an input-volume model. Apply actual cache, output and tool rates to calculate the bill.

Worked arithmetic · Optional reference · Back to the talk

Include the write before counting savings

Same eligible prefix; all later requests hit the cache. Normalize ordinary input cost to 1 per request. Total cached cost = w + (n − 1)r Caching saves when w + (n − 1)r < n. Example r = 0.10: w = 1.25 → savings at 2 requests w = 2.00 → savings at 3 requests

Illustrative multipliers: verify model, platform, TTL and expiry rules. A cache miss changes the calculation.

Make the retry edge explicit

PSEUDOCODE — not a harness API findings = investigate(rule, calculation, export) plan = reconcile(findings, acceptance_cases) latest_failures = [] for attempt in range(3): patch = implement(plan, latest_failures) result = run_acceptance_checks(patch) if result.passed: return request_review(patch, result) latest_failures = result.failures return report_blocked(latest_failures)

Use enforced tool, time and cost limits around the workflow. Assign an owner to integration.
