Context · the problem

A full window hurts you three ways

01

It degrades

Quality slips before the hard limit.

02

It re-bills

Every turn resends the window.

03

It re-caches

An early edit breaks the cache.

One fix for all three: decide on purpose what stays in the window.

Context · reset on purpose

/clear ends a task; /compact carries one on

Full reset

The task is done and the next one is unrelated.

Summarise and continue

/compact

Compaction has a cost too: the summary pass reads the whole window once more.
