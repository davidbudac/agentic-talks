04
Setup · four meanings

Which graph do you mean?

Knowledge graph

Typed relationships between real things. What the system knows.

Retrieval graphGraphRAG

Entities, passages and communities. How the model finds evidence.

Workflow graph

Agents, tools and gates. What the app does.

GNN

A model that learns from graph data. Out of scope today.

Real systems often combine the first three. When someone says graph engineering, ask which graph.

Decide · failure math

The failure math

0.85⁵ ≈ 44%

At 85% per hop, a five-hop chain is wrong more often than right.

“A graph of weak nodes is just slop produced in parallel.”

AI Builder Club · Jul 2026

Retrieval hops and agent hand-offs decay alike. Make each node strong before you add another edge.

Decide · the table

The decision table

Single-hop Q&A over docs

Vector or hybrid RAG. No graph.

Multi-hop, temporal or audited

A knowledge graph with hybrid retrieval

Cross-session agent memory

Files first; a graph once facts contradict or age

Repo context

Agentic grep; a code-graph MCP for large monorepos

Agent control flow

A loop first; an explicit graph for compliance or repeatability

Anything else

Keyword search: Amazon reached 94.5% of RAG faithfulness with no vector store

Graphs are becoming one tool the agent picks per query.
