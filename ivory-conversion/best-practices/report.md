## Structural changes worth a look

- **Slide 29:** the source has `.note` + `.src` + a second `.note` holding only the reference link. Ivory allows one footnote plus one source line. I merged the reference link into the `.src` line: `Applied example · supporting documentation · Optional reference material`. There is no precedent for a slide with both `.src` and a reference link. The siblings move the reference link into `.src` alone, but here `.src` was already taken. The alternative is to append the link to the `.note` sentence.
- **Slide 17 (flag):** the source code block is a header line followed by "1." … "4.". The panel's generated line numbers sit beside them as `02 1.`, `03 2.` … `05 4.`, so there are two numbering systems, off by one. No text refers to line numbers ("first line" and the like). This matches the committed orchestrating-agents-ivory 17. Ivory has no unnumbered code variant, and the text must stay. The only text-preserving alternative I found is a one-column `.tbl` with the header as `th`. I did not use it because it is not a kitchen-sink pattern. Parent: decide whether this is acceptable.
- **Clay** appears on at most one element per slide:
  - the title header label;
  - `.tile.key` on 03 ("Your next step"), 04 ("After") and 14 ("Acceptance test");
  - `.key` on "Replacement:" (05), `$0.0506` (10), `VERIFY:` (21) and "failed" (26);
  - `th.key` Compare (13).

  Every other slide is a set of equals and has no clay. The judgement calls are 03 and 14: claim versus test, where the test is what the headline asks for. Clay on 05 ("Replacement:") and 26 ("failed") marks the single result. Drop any of these if the parent wants a stricter reading.
