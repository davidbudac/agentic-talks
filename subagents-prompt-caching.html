Split the work · subagents

Delegate a question; ask for evidence back

  • Fresh helpers need a self-contained task and relevant inputs. Forks can inherit existing history.
  • Keep intermediate investigation in the helper’s context; return findings with file references.
  • Review the result. Delegation adds coordination cost and does not itself isolate filesystem access.

Example return: VAT calculation locations, the failing path, supporting lines and unresolved questions.

The bill · KV cache · how

Caching reuses work on a matching prefix

  • A prompt cache can reuse computed state for eligible, matching earlier content.
  • Keep reusable instructions stable. Changes can invalidate the affected prefix and later content.
  • Inspect cache usage records: expiry, minimum length and provider rules affect whether you get a hit.

Animation shows prefix reuse. Its price label is illustrative; rates vary. Cached content still occupies context.

15
Worked arithmetic

Include the write before counting savings

Same eligible prefix; all later requests hit the cache. Normalize ordinary input cost to 1 per request. Total cached cost = w + (n − 1)r Caching saves when w + (n − 1)r < n. Example r = 0.10: w = 1.25 → savings at 2 requests w = 2.00 → savings at 3 requests

Illustrative multipliers: verify model, platform, TTL and expiry rules. A cache miss changes the calculation.

In practice

Reuse depends on a live, eligible entry

  • Claude documents a default five-minute cache lifetime and an optional one-hour lifetime.
  • A use refreshes the lifetime from the request start; generation time counts against it.
  • Minimum prefix length, matching, platform support and writes also determine hits.

Check the usage fields and current configuration. Provider caching documentation

18
In practice

Concurrent requests do not guarantee shared hits

1. Prepare one eligible prefix and matching cache settings. 2. Start a request that writes that prefix. 3. Wait until its response begins and the entry is available. 4. Send matching helper requests; inspect cache usage.

Cold simultaneous requests can duplicate cache writes. Claude cache limits

In practice

Separate investigation. Verify reuse.

  • Give helpers explicit inputs and require evidence in the return.
  • Separate working contexts do not enforce filesystem or network isolation.
  • Warm eligible shared prefixes and inspect actual cache reads and writes.

Delegation changes where work accumulates. Caching changes the processing cost of repeated input.
