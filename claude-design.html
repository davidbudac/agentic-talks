Briefs to steal

Four briefs to steal

deck

An 8-slide pitch deck for [product] for non-technical execs: problem, solution, demo screenshot, market, pricing, roadmap, team, ask.

dashboard

An analytics dashboard: revenue, active users and churn as top-row metric cards, a monthly trend chart below, filterable by region and plan.

onboarding flow

A 4-screen mobile onboarding flow: welcome, permissions, profile setup, first-run tips. Clickable, with a progress indicator.

internal tool

A request-intake form for the legal team: requester info, a request-type dropdown, conditional fields per type, urgency, file upload.

Each one: audience, sections, content per section, one constraint.

Pitfalls

Six pitfalls early users hit

Vague feedback

Name the component and give a number.

Judging round one

The value shows up in rounds two to four.

Pixel-perfecting

Get to 90% here, finish in Canva.

Huge repos

Link from Claude Code or attach one folder.

Missing comments

Known issue: paste the note into chat.

Co-editing

Still basic. One driver, many reviewers.
