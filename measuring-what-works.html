smevals turns the loop into files

Evala set of tasks for one capability
Taskone exercise, as YAML
Configmodel, parameters, prompts, tools
Runnerany executable: a model call or an agent harness
Runimmutable record of task × config × model
Graderchecks in sequence, combined into a score

Open source, MIT · github.com/prime-radiant-inc/smevals

Evals · grading

Grade with cheap gates first and the judge last

graders/default.yaml
checks: # run in order - checker: contains value: "<svg" required: true # fail: stop here - checker: ../checkers/render-svg creates: render.png - checker: ../checkers/llm-judge scoring: # last score wins pass_threshold: 0.5
  • A failed required gate stops the sequence, so the judge never scores junk.
  • The grade keeps the last score a check emits. Put the judge at the end.
  • Runs are immutable: re-grade old runs with a new rubric.
  • Reports show mean ± stderr per config × model.

Traces · capture

A trace is the whole transcript

session transcript · illustrative
t1userfix the failing auth test
t2toolRead src/auth.ts212 lines
t3toolBash npm test auth1 failed
t4thinkexpiry compares local time
t5toolEdit src/auth.ts+3 −1
t6toolBash npm test auth12 passed

Every turn, tool call and result, plus reasoning where the harness records it.

A failed run stops being “it didn’t work” and becomes turn t3.
